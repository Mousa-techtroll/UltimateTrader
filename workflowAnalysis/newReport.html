The two-sentence verdict

One correlated long-gold book, defended by stops — not by the adaptive logic the code appears to contain.

Edge

The real realized edge is a single regime-conditioned bet: buy gold dips in an uptrend through a handful of near-redundant, tie-biased long triggers (~half the trades by count but ~80% of the net profit), plus a genuinely diversifying death-cross-gated mean-reversion short that pays only in a sustained gold downtrend and sleeps for years otherwise — a thin, small-positive-expectancy long-continuation factor with dormant short insurance, measured on unrealistic zero-slippage, in-sample-curated fills.

Risk

The risk machine is net-conservative and intact where it matters — correct fixed-fractional sizing, an EC-v3 graded drawdown reducer, a 3% daily halt, a 5% portfolio cap, and per-position stops — but a broad band of adaptive protection is silently asleep (uninitialized risk plugin, dead exit plugins, an unreachable B tier, RSI frozen at 50, a vol-inflating ATR mismatch that only ever shaves size). The EA under-risks rather than over-risks.

On the production configuration, UltimateTrader presents as an ~11-strategy, multi-layer SMC and adaptive-risk system. Read from source, it operates as something much smaller: one correlated long-gold trend-continuation bet (Engulfing / PinBar / MA-Cross plus the long-biased engines) and one genuinely diversifying conditional short (the D1 death-cross "Rubber-Band" fade), sized by an inline fallback, gated mainly by regime, a point-threshold quality tier, and the fact that the registered plugin set is long-only.

The defining theme of this evaluation is the gap between surface and operation. A large fraction of the advertised sophistication never executes on prod — the SMC confluence floor, the RSI/momentum gate, the adaptive risk-scaling steps, the HTF short-veto, breakout-probation, the SETUP_B tier, and most consequentially the entire exit-plugin layer. None of this corrupts trade direction or oversizes a position, which is why the register tops out at HIGH and not CRITICAL — but it means the EA is honestly described by far less than its codebase implies.

Only one strategy clears the positive-edge gate — the Rubber-Band conditional short (9/10). Its D1 death-cross gate is the architecturally correct way to short a structurally-bullish asset: it arms only once gold itself has confirmed a downtrend, then fades overextension to EMA21. The catch is that it is episodic — essentially all of its positive R came from a single 2021H2–2022 window, with zero trades in 2019, 2020, 2024, and 2025. It is regime insurance, not a workhorse.

OB-Retest is the only other genuinely structural mode — a real triple AND-gate (order-block zone ∧ same-direction BOS/CHoCH ∧ rejection), all on closed bars, and notably it does not call the look-ahead helpers that quarantine the Displacement mode. But it fired zero trades in the artifact. That inertness is structural starvation (the conjunction is rare, and it loses the strict-> tie-rank at its fixed 82/80 score) rather than a config-off choice — so it cannot be assumed beneficial without an isolation run.

Track A — implementation & logic

Findings register

Two axes, read together. Severity grades the code defect in isolation. Realized impact (0–3) grades how much it actually moved P&L or risk on the production config. The signature result of this audit is that several HIGH-severity findings carry impact 0–1 — because they sit on dead, dormant, or zero-firing paths.

High severity

RXT-02

The entire exit-plugin layer never initializes — CheckExitPlugins is a permanent no-op

HIGHimpact 2

All four live exit plugins — CDailyLossHaltExit, CWeekendCloseExit, CMaxAgeExit, and CRegimeAwareExit (the only structure-aware exit) — are constructed and registered, but Initialize() is never called on any of them. The base constructor leaves m_isInitialized=false, so every CheckForExitSignal early-returns on its guard. Managed exits never fire: no regime/macro-opposition exit, no 72-hour max-age close, no daily-loss position close.

Why HIGH and not CRITICAL: three backstops survive — per-position broker stop-losses are intact, weekend gap risk has a coordinator-native closer, and CanTrade() still blocks new entries on a daily loss. It is a capital-protection gap, not an edge-defining one.

FILT-04

RSI is frozen at 50 — the momentum filter it is sourced from is disabled

HIGHimpact 2

RSI is sole-sourced from CMomentumFilter, which is off on prod (InpEnableMomentum=false). With no alternate handle, GetCurrentRSI() returns a hardcoded 50 for every signal. This silently kills both the validator's RSI-extreme exceptions and the CSetupEvaluator "+3 quality points for extreme RSI."

The effect is one-directional and conservative: the validator becomes stricter, and quality tiers (hence risk %) deflate. It changes which trades fire and at what size, but never corrupts direction. Note that the per-tier expectancy seen in the CSV was produced under this RSI-blind scoring.

CTX-10

ATR units mismatch in the live risk-multiplier stack (H4 current ÷ H1 average)

HIGHimpact 1 · under-risk

GetATRCurrent() returns an H4 ATR (from CRegimeClassifier) while GetATRAverage() returns an H1 ATR (from CVolatilityRegimeManager). That mismatched current/average pair feeds the EC-v3 volatility controller and two other consumers — so the vol ratio reads systematically high.

Direction matters: the EC-v3 vol layer only ever reduces size, floored at 0.90. So the mismatch produces a slight, systematic under-risk — it never over-sizes. A real units bug with a conservative consequence.

ENG-01 / ENG-02 / WT3-01

Displacement mode hard-gates on a forming weekly bar — repaint-instability

HIGH codeimpact 0 · latent

In CLiquidityEngine's Displacement mode, ScoreLiquidityLevel reads the forming weekly bar iHigh/iLow(…,PERIOD_W1,0) and feeds it into a hard gate (liq_score >= 2); GetLocationPenalty additionally reads the forming daily bar (…,PERIOD_D1,0) into the score.

Adjudication of the census contradiction: this is not a future-data leak — a forming-HTF running extreme read at H1-bar-open is a known-now value. But because that weekly extreme keeps moving as the week develops, using it as a hard gate is a genuine repaint-instability: the same setup evaluated on different H1 bars within the week can pass or fail the gate. Realized impact is zero today because the whole Liquidity engine fired no trades — but it is a latent landmine that must be fixed (shift 0→1) before the mode can be graded in an isolation test.

Data-contradiction resolutions

Five contradictions between recon impressions and unit findings, each resolved with a source citation.

a

Resolved. The wired inline fallback reaches sizing; the risk plugin is dormant by design and its lot math is algebraically identical. (U8 RXT-01)

Resolved. SETUP_B is unreachable — InpPointsBSetup=7 sits behind the A≥7 check, so B+ (6) is the effective floor. (RXT-14)

Resolved. Reachable, but near-measure-zero on gold H4 (when ADX<15, ATR is almost always contracting → routes to RANGING). Dead by construction, not by bug. (WT-7)

d

Resolved. The CSV is a Model-1 artifact; used as a directional cross-reference only, never as a verdict, throughout this report.

e

Look-ahead census ("zero HIGH") vs. ENG-01/02 (Displacement W1/D1 = HIGH)

Resolved. Both half-right: there is no future-data leak (census correct), but the W1 read is a hard gate whose level moves intrabar (the units correct) — precisely classified as repaint-instability, HIGH by code, zero realized today. (Phase-2 adversarial)

Prioritized recommendations

  1. Decide the exit-plugin layer (RXT-02)

    Either initialize the four exit plugins — restoring the structure-aware regime exit, daily-loss position-close, and 72h max-age — or formally delete them and document that exits = SL / TP-ladder / Chandelier / weekend-native.

    Kill-criterion: a backtest with the regime-aware exit live must not degrade PF vs. current; if it does, the no-op was accidentally beneficial and should be made explicit.

  2. Fix the ATR vol-ratio units (CTX-10)

    Make GetATRCurrent and GetATRAverage the same timeframe, then re-confirm the EC-v3 multiplier.

    Falsifiable: the realized vol-ratio distribution should center near 1.0 in normal regimes (today it reads systematically high).

  3. Adjudicate and, if real, fix the Displacement W1/D1 gate (ENG-01/02)

    A one-line shift (0→1) per read removes the repaint-instability; only then can the Displacement mode be fairly graded in an isolation test.

  4. Resolve RSI sourcing (FILT-04)

    Either add an RSI handle independent of the disabled momentum filter, or remove the RSI-dependent tier bonus and validator exceptions so tiers are not silently deflated.

  5. Re-state the EA honestly

    Bring the advertised strategy count and feature list in line with the operative reality — one long cluster plus one conditional short, and the inert-feature inventory above. The tie-break (PORT-02) should also be re-examined, since it currently favors the lowest-expectancy trigger.

  6. Lower priority

    EXE-01 netting bind, DET-01 spread-median trim, NUM-03 STOPS_LEVEL check, the exposure-cap denominator (ORC-02), and dead-input / dead-file cleanup.

How this was produced

Method & scope

This evaluation was built entirely from source — UltimateTrader.mq5, UltimateTrader_Inputs.mqh, and Include/**/*.mqh — reading no existing documentation, HTML reports, or commit history, so the assessment adjudicates the code on its own terms. Work was fanned out across 19 parallel audit units in two tracks (implementation/logic and trading/edge), each reporting line-anchored findings in a shared schema, then reconciled in a dual-agent adversarial pass with a single build-check compile.

Scope boundaries. Edge verdicts are static and structural — fidelity to the named concept, look-ahead cleanliness, and posture justification read from code. No new backtests were run. The all_trades_v15.csv record is a Model-1 (1-minute-OHLC) artifact reflecting one whole-pipeline build, used as a directional cross-reference only and never as an edge verdict. No fixes or commits were made; the recommendations are listed, not executed.
