A field manual for a gold-trading machine

How the gold bot works, one chapter at a time.

This is an automated trading program — a "bot" — that buys and sells gold on its own, around the clock. It doesn't guess or chase every price flicker. Once an hour it runs the same disciplined routine, start to finish. This book explains that routine in plain language, no trading background needed — a chapter for each link in the chain.

The chain of execution

From a hunch to a managed trade, in seven links

Every trade that ever gets placed walks this exact chain in order. A break at any link and the idea is dropped until next hour. Each link is a chapter of this book.

Read the room

Size up the trend, the market's mood, the backdrop and the clock.

Interview the scouts

Ask every specialist strategy: "do you see your setup right now?"

Pick the best one

Score every "yes" and hire exactly one — the strongest idea this hour.

Run the gauntlet

Put it through a wall of safety checks; one failure cancels it.

Size to the risk

Work backwards from the stop so a loss costs a fixed, small amount.

Enter

Place the order, re-checking the live price and spread one last time.

Manage & exit

Bank profit in slices, trail a runner, and close on the exit rules.
