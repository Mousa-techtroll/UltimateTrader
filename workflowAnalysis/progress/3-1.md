## S6-box wiring + S6-long-only inspection note (for the GATE / Phase 3.8 when engines turn ON)
- **Box detector correctly lifecycle-managed:** ctor NULLs it; `Initialize()` `new`s + `Init()`s it (handles created once); `CheckForEntrySignal()` `Update()`s it once per bar after the per-bar guard; `Deinitialize()` `Deinit()`s + deletes it AFTER S6 is freed. - **Box detector wired into S6:** `m_s6 = new CFailedBreakReversal(m_box_detector)` passes the real (non-NULL) detector. In `CFailedBreakReversal::CheckForEntrySignal` (:113-117) the box edges (`GetBoxHigh`/`GetBoxLow`) are now added to `levels_above`/`levels_below` whenever `m_range_box.IsBoxValid()`, restoring the intended box-edge sweep population on top of PDH/PDL.
- **S6 LONG-only on gold is intact:** the SHORT loop in `CFailedBreakReversal` is short-circuited by `if(!g_profileEnableS6Short) return signal;` (:191) BEFORE the `levels_above` loop runs. Box edges feed `levels_above`, but that loop is never reached on the gold profile (S6 short = −8.9R), so the new box edges CANNOT resurrect short S6. Additionally the HTF-uptrend SHORT veto (Phase 3.5, hard-ON, no disable input) gates all engine shorts at the orchestrator once it lands — a second, independent guard. The reversal engine's own `AdoptSignal` also applies a premium/discount location + structure-shift gate to any adopted short.
