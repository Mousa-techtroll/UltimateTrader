- **Conservative-min anchor:** `CTrendContinuationEngine.mqh` `BuildZoneLong()` — `zone_low` initialized to `GetSwingLow()`, then replaced by `lookback_low` iff `lookback_low > 0 && (zone_low <= 0 || lookback_low < zone_low)`. ⇒ `zone_low` is the LOWER (more conservative) of the two, exactly per Option A. - **`m_min_sl_points` floor respected:** the conservative-min anchor is by construction never tighter (never higher) than `GetSwingLow()`-only, so `risk = entry - sl` only grows; the existing `if(risk < m_min_sl_points * _Point) return signal;` reject still fires for an over-tight SL and is never bypassed. A LOWER zone_low cannot introduce a min-SL violation.
