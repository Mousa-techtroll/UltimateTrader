Status update — 2026-07-23

The exit / trade-management layer now has a built (but dormant) redesign

This report is a dated professional-review snapshot — every finding, score and scenario below is preserved exactly as written. Since it was produced, the exit / trade-management layer it reviews has been rebuilt in code as a built-but-DORMANT Exit-Momentum Platform. It is not live: it changes no production trade today and ran in none of the EA's results.

  • A closed-bar momentum-reading feature (shift ≥ 1) that never fabricates a value — every reading starts unavailable and only a successful compute flips it on (the structural answer to any "invented / lagging indicator" concern).
  • A strategy-aware exit engine: five policy families (trend-continuation · breakout · mean-reversion · reversal · crash) resolved into per-signal profiles; the position coordinator stays the sole broker-action owner — policies only propose exits, never place orders.
  • Runs in SHADOW mode only (observe + log), proven decision-free and byte-identical to production on both data feeds, with both master switches OFF by default.
  • One activation experiment — TREND_TRAIL_WIDEN_V1 — was tested and NOT adopted (immaterial vs the wide trail already shipped). No profile is production-active; activation is evidence-gated, one at a time.

This audit deliberately used no result metrics, so it cites no backtest figures to refresh. The platform does not touch the report's open gaps — news, chop, entry-location and correlation — so the 60 / 100 verdict and the roadmap below stand.

The core comparison

A skilled gold trader reasons in a fixed order — context first, setup second, risk third, execution last. The EA follows most of this skeleton, and crucially checks risk before generating signals; the breakdowns are in liquidity-as-frame, news, and entry location.

Beyond the framework

Added professional dimensions

Setup-stack correlation — 2/5

The ~12 setups are sold as a portfolio but ~9 fire on the same "buy the gold uptrend on a shallow retrace" state. The only aggregate control is a position count (InpMaxPositions=5) — no per-direction or per-family risk budget, so five concurrent "independent" longs are really ~5× one bet.

Multi-timeframe coherence — 4/5

A genuine strength: D1/H4/H1 are fused into one bias with explicit conflict-resolution (D1≠H4 rejects unless an H4-tiebreak/RSI override). The only soft spot is a bullish default when MA200 data is missing.

Parameter / overfitting surface — 2/5

418 inputs, no config version, no init range-validation. Live param comments inline per-year backtest PnL/R and dated optimization stamps — the config file doubles as an optimization log, the classic curve-fit tell.

Dormant-module & complexity — 2/5

~20 dead source files; the advertised plugin architecture (CPluginManager/Registry/Mediator) is not the live mechanism — the EA hand-rolls registration. InpEnableNewsFlat=true reads as "news on" but is silently neutralized.

Before serious testing

Prioritized fix roadmap

Evaluation only — listed, not executed. Ordered by leverage. The first three close every critical red flag and most scenario failures.

  1. Make news protection live & fail-closed

    Decouple IsDataDay() from InpEnableMultiStrategy; add a router-independent NO_TRADE_NEWS_WINDOW skip to the always-on OnTick gate; ensure the static blackout engages when the calendar is unavailable.

    Closes §12, scenarios 6 & 15, two critical red flags — highest leverage.

  2. Add stand-aside discipline

    A single-candle extension cap on the core candle setups (no chasing); a chop / NY-lunch dead-zone or make CHOPPY reachable; and a post-loss / flip-flop cooldown.

    Closes scenarios 9, 10, 14.

  3. Add entry-location quality

    A limit / retrace entry layer instead of market-on-close, and turn the reward-room / PDH obstacle gate ON by default.

    Closes §14 and scenario 5.

  4. Budget the correlated long book

    A per-direction / per-family risk budget rather than a bare position count, so the long-trend-continuation cluster is sized as one bet.

    Closes setup-correlation.

  5. Close the execution & audit gaps

    Wire CheckSlippage so InpMaxSlippagePoints is live; add an OnInit broker-spec validation gate; add a post-failure cooldown; add stop/target-reason fields + structured NO_TRADE journal rows.

  6. Govern the parameters

    Add a config version and init-time range validation on dangerous inputs; prune the ~20 dead files / dormant engine stack or document them as inert.

  7. Stop over-claiming concepts

    Build or remove the enum-only concepts (breaker, inducement, OTE, CRT); rename the proxy "swing"/"premium-discount" and have the live engines consume the faithful CMarketContext versions.
